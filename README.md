# GET NEXT LINE
## Description
GET NEXT LINE is a project used to read a text file **one line at a time**  

## Instructions
### installation
```bash
git clone https://github.com/42learners/Common-Core---GetNextLine-fbb22f11-26be-405c-80e2-c797cb54175e.git
```
### Compilation
Then compile your file with the generated ``get_next_line function`` by adding in the main 

``` C
#include "get_next_line.h"
````
```bash
cc -D [BUFFER_size] get_next_line.c get_next_line_utils.c main.c
```
